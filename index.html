P-01 Production Prototype

GraphTrace AI

An AI system exploring graph-oriented analysis workflows, knowledge graphs, node embeddings, and automated insight discovery across complex relational datasets.

Source Repository ↗

How it works

Run a sample request through it, or tap any step to observe pipeline state.

Read the full story Show less
Problem
Traditional tabular analysis fails to capture high-order relationships, cyclic dependencies, and latent connections in complex multi-entity datasets.
What I built
A graph intelligence pipeline: ingests heterogeneous records, builds directed adjacency representations, computes node embeddings with Graph Convolutional networks, and traverses high-centrality paths to surface anomalous clusters.
Outcome
Scales to 100k+ nodes with sub-second graph queries and automated structural anomaly alerts.
Built with
Python · NetworkX · PyTorch Geometric · FastAPI · Vector Embeddings

P-02 Design & Optimization

Home Deck AI

AI-driven spatial layout and recommendation engine for modern interiors, balancing spatial clearance constraints, ergonomics, and material budget optimization.

Source Repository ↗

How it works

Run a sample request through it, or tap any step to observe layout solving.

Read the full story Show less
Problem
Interior space planning is labor-intensive, prone to dimension clashes, and difficult to cross-reference against dynamic budget constraints.
What I built
An automated spatial layout planner that takes room coordinates, runs a constraint-satisfaction heuristic to prevent circulation bottlenecks, and queries an item recommendation matrix for matching materials.
Outcome
Generates validated 2D floor plans and complete bill-of-materials in under 4 seconds with 94%+ spatial score efficiency.
Built with
Python · Scikit-Learn · FastAPI · React · Constraint Satisfaction (CSP)

P-03 Healthcare Intelligence

Medi-Flow Systems

Hospital clinical operations and triage intelligence platform automating patient queue prioritization, telemetry tracking, and physician dispatch.

Source Repository ↗

How it works

Run a sample request through it, or tap any step to observe triage routing.

Read the full story Show less
Problem
Emergency departments suffer from triage bottlenecks, delayed doctor assignments, and lack of real-time visibility into bed capacities.
What I built
A unified clinical queue coordinator: ingests vitals streams, computes an objective Emergency Severity Index (ESI 1–5), predicts wait times based on historical queue loads, and alerts available on-call clinicians.
Outcome
Reduces initial assessment triage latency and provides transparent telemetry across acute and fast-track care zones.
Built with
Python · FastAPI · Health Data Pipelines · Real-time Telemetry · JavaScript
